# Fonts

## DroidSansFallbackFull.ttf

Used to render Chinese (CJK) text in jsPDF exports. jsPDF only ships Latin
fonts, so without an embedded CJK font Chinese characters appear as boxes.

- Font: Droid Sans Fallback (Full)
